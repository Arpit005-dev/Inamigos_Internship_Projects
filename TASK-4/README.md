## 📝 Task Overview

The objective of this task was to create a simple Figma design highlighting important features that should be included in an NGO website.

The design focuses on clarity, trust, transparency, user participation, and social impact.

---

## 🎯 Objective

- Identify essential features required in an NGO website
- Present the selected features through a simple visual layout
- Explain the purpose of each feature
- Suggest improvements that can be implemented on the foundation's website

---

## ✨ Features Highlighted

### 1. 💳 Donation Section

A clearly visible donation section that allows supporters to contribute using secure payment options.

**Suggested elements:**

- Preset donation amounts
- Custom donation amount
- Secure payment gateway
- Explanation of fund utilization
- Donation confirmation message

### 2. 🙋 Volunteer Registration

A simple volunteer form that allows interested people to join the organization.

**Suggested form fields:**

- Full name
- Email address
- Phone number
- Skills
- Availability
- Preferred volunteering area

### 3. 📊 Impact Showcase

A dedicated section presenting the organization's achievements and measurable impact.

**Suggested elements:**

- Number of people supported
- Completed projects
- Active volunteers
- Communities reached
- Photographs and success stories

### 4. 📢 Campaigns and Causes

A section displaying current and upcoming social-impact campaigns.

Each campaign can include:

- Campaign title
- Short description
- Fundraising target
- Progress indicator
- Deadline
- Donate or support button

### 5. 💬 Testimonials and Success Stories

Real experiences from beneficiaries, volunteers, and donors can increase trust and credibility.

**Suggested content:**

- Beneficiary stories
- Volunteer experiences
- Donor feedback
- Photographs
- Short video testimonials

---

## 🎨 Design Approach

The design uses a clean NGO-focused interface with:

- Green and white colour palette
- Clear headings and labels
- Simple cards for each feature
- Strong call-to-action buttons
- Easy-to-understand layout
- Responsive website concept
