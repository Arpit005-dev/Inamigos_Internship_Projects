## 🚀 How to Run the Projects Locally

```bash
git clone https://github.com/Arpit005-dev/Inamigos_Internship_Projects.git
```

### 2. Open the project folder

```bash
cd Inamigos_Internship_Projects
```

### 3. Open any task folder

```bash
cd TASK-1
```

### 4. Run the website

Open the `index.html` file directly in your browser or use the **Live Server** extension in Visual Studio Code.

## 🌐 Deployment

The web projects in this repository are deployed using **GitHub Pages**.

To deploy a project:

1. Open the GitHub repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and `/root` folder.
6. Click **Save**.
