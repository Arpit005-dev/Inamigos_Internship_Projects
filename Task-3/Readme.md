## 📖 About the Project

AstraLearn AI is an educational platform concept that demonstrates how artificial intelligence can improve the online learning experience.

The website provides a modern interface where students can explore AI-powered learning tools, personalised courses, smart assistance, progress tracking, and interactive educational resources.

This project was created as part of the **InAmigos Foundation AI Web Development Internship**.

## 💻 Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/Arpit005-dev/Inamigos_Internship_Projects.git
```

### 2. Open the project folder

```bash
cd Inamigos_Internship_Projects/Task-3/Task3_AI_Website_AstraLearn
```

### 3. Launch the website

Open the `index.html` file directly in your browser.

You can also use the **Live Server** extension in Visual Studio Code:

1. Open the project folder in VS Code.
2. Right-click on `index.html`.
3. Select **Open with Live Server**.
