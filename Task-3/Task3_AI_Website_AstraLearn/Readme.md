# 🤖 AstraLearn — AI-Powered Education Website

This project was developed as **Task 3 of my AI Web Development Internship at InAmigos Foundation**.

The goal of this project was to create a complete, responsive, and visually appealing website using AI-assisted tools. The website demonstrates how artificial intelligence can support personalized learning, student guidance, progress tracking, and interactive education.

## 🚀 Live Demo

🔗 [View the Live Website](https://arpit005-dev.github.io/Inamigos_Internship_Projects/Task-3/Task3_AI_Website_AstraLearn/)

## 📌 About the Project

**AstraLearn** is a modern AI-powered education website concept designed to make learning more personalized, interactive, and accessible.

The website introduces visitors to AI-based learning services and explains how students can use intelligent tools to:

- Receive personalized study guidance
- Get instant academic support
- Track learning progress
- Build better study routines
- Explore suitable learning paths
- Contact the platform for more information
