# 🌍 NGO Awareness Webpage — InAmigos Foundation

This project was developed as **Task 1 of my Web Development Internship at InAmigos Foundation**.

The goal of this project was to create an informative, responsive, and visually appealing NGO awareness webpage that highlights the foundation’s initiatives, social impact, ongoing projects, and opportunities for people to contribute.

## 🚀 Live Demo

🔗 [View the Live Website](https://arpit005-dev.github.io/Inamigos_Internship_Projects/TASK-1/)

## 📌 About the Project

The webpage introduces visitors to **InAmigos Foundation** and presents information about its ongoing projects, social initiatives, and community impact.

It also encourages visitors to participate by:

* Volunteering for social initiatives
* Supporting campaigns
* Spreading awareness
* Contributing to community projects

## ✨ Features

* Responsive and mobile-friendly design
* Clean and structured user interface
* NGO introduction section
* Ongoing projects section
* Social impact and purpose section
* Images and visual content
* Volunteer and support call-to-action
* Smooth scrolling navigation
* Interactive buttons
* Hover effects
* Animated decorative lines
* Scroll-based content animations
* User-friendly layout and navigation

## 🛠️ Technologies Used

* **HTML5** — Website structure and content
* **CSS3** — Styling, layout, responsiveness, and animations
