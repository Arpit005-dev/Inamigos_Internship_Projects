🌍 NGO Awareness Webpage — InAmigos Foundation
This project was developed as Task 1 of my Web Development Internship at InAmigos Foundation.

The goal of this project is to create an informative, responsive, and visually appealing NGO awareness webpage that highlights the foundation’s initiatives, social impact, and opportunities for people to contribute.

🚀 Live Demo
🔗https://arpit005-dev.github.io/Inamigos_Intership_Projects/TASK-1/

📌 About the Project
The webpage introduces visitors to InAmigos Foundation and presents information about its ongoing projects, social initiatives, and community impact.

It also encourages users to participate through volunteering, supporting campaigns, and spreading awareness.
