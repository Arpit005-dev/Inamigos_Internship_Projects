## 💡 Major Recommendations

### 1. Improve Calls to Action

Use **“Donate Now”** consistently instead of “Donate Us” and standardize action labels across the website.

### 2. Simplify Navigation

Reduce equal-weight navigation items and group related pages under clearer categories.

### 3. Lead With Verified Impact

Display dated and verifiable impact statistics near the homepage hero section.

### 4. Improve the About Page

Break long content into clear sections such as:

- Mission
- Vision
- Values
- History
- Leadership
- Registrations
- Annual Impact

### 5. Strengthen Trust and Credibility

Add authentic team information, organizational history, registration details, and verifiable credentials.

### 6. Organize Gallery Content

Introduce filters based on:

- Project
- Year
- Location

Each image should include a caption, date, place, and outcome.

### 7. Improve Blog Presentation

Use meaningful excerpts, topic tags, readable titles, and clear **“Read Article”** links.

### 8. Maintain Contact Consistency

Use one official support email across the header, contact page, footer, and structured data.

### 9. Add Quick-Contact Options

Include:

- Google Maps
- Get Directions
- Click-to-call
- WhatsApp
- Response hours

### 10. Improve Contact Form Experience

Add visible labels, inline validation, success/error messages, spam protection, and a clear privacy statement.

### 11. Run Accessibility and Performance Audits

Test keyboard navigation, colour contrast, alt text, heading structure, image optimization, touch targets, and responsiveness.

## 🖥️ Suggested Homepage Direction

The proposed homepage redesign focuses on answering three important questions for first-time visitors:

> **What does the foundation do?**  
> **What impact has it achieved?**  
> **How can visitors participate?**

The suggested redesign includes:

- Simplified navigation
- Clear primary calls to action
- Impact statistics
- Structured cause cards
- Better storytelling
- Improved visual hierarchy
- More visible trust signals
